You spoke of Themida.  It is 100% pain in ass, I know...
When I found myself unable to unpack new versions or version
using RISC opcodes, in the past....
I would locate the code where real Intel opcode I need modify
and the corresponding file offset... then use hex editor to modify the
Themida 'VM opcodes' until I manage to change the unpack version
that run in memory.  Buildzone mostly modification of conditional
jmp instructions, so.. with much patience and examination this
was one way to 'work around' Themida.

If Themida CRC check file for modifications, this will not work
also.. it take much time, patience and very boring.
